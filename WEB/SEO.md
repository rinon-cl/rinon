## SEO integral

- [ ] Arquitectura e intención de búsqueda.
- [ ] Titles, descripciones y encabezados únicos.
- [ ] Canonical, robots y sitemap.
- [ ] Schema apropiado y verificable.
- [ ] Enlaces internos y breadcrumbs.
- [ ] Rendimiento y Core Web Vitals.
- [ ] Accesibilidad y experiencia móvil.
- [ ] Google Business Profile y consistencia de datos locales cuando aplique.
- [ ] Contenidos de autoridad y preguntas frecuentes.
- [ ] Analítica, Search Console y medición de leads.

## Control de calidad

- [ ] No hay páginas doorway ni contenido generado solo cambiando la ciudad.
- [ ] Cada página responde una intención concreta.
- [ ] Las afirmaciones locales y comerciales son demostrables.
- [ ] La estrategia fue aprobada antes de generar páginas en volumen.
